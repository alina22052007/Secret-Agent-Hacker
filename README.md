# SECRET AGENT

An interactive, single-file training terminal made with HTML, CSS, and vanilla JavaScript. It runs locally or on GitHub Pages without a backend, build step, or external libraries.

## Features

- Interactive terminal commands and clickable simulation tools
- Operation Zero mission briefing with a three-step progress bar
- Signal, decrypt, and stealth telemetry indicators
- Hidden Caesar-shift cipher mini-game
- Optional sound effects and animated falling-code background
- Responsive, dark neon interface

All terminal tools are fictional, local demonstrations. The page does not connect to other systems or require a backend.

## Run locally

Open `index.html` in a modern browser. The app has no installation or build step.

## Publish with GitHub Pages

Upload `index.html`, `README.md`, `DEBUGGING_NOTE.txt`, and `CODE_EXPLANATION.txt` to the root of the existing repository. In that repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. After GitHub finishes publishing, copy the Pages URL into the placeholder above.
